## 📁 Estrutura do Repositório
O projeto está organizado por nível de complexidade ou por regras de negócio:
* `/fudamentos`: Filtros simples, agrupamentos e ordenações (`WHERE`, `GROUP BY`, `HAVING`).
* `/consultas-avancadas`: Uso de subqueries, CTEs (`WITH`) e funções de janela (`WINDOW FUNCTIONS`).
* `/modelagem-de-dados`: Modelagem e consultas focadas em cenários reais (Ex: Análise de Vendas, E-commerce).

* ## 🚀 Conceitos SQL Demonstrados
* **Junções**: `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN`.
* **Agregações**: `SUM`, `AVG`, `COUNT`, `MIN`, `MAX`.
* **Funções de Janela**: `ROW_NUMBER()`, `RANK()`, `PARTITION BY`.
* **Otimização**: Criação de índices e análise de planos de execução (`EXPLAIN`)
